# ITS-Typst

Template Tugas Akhir ITS berbasis Next.js + TypeScript

</div>

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Package Manager**: pnpm

## Memulai

```bash
# Install dependensi
pnpm install

# Jalankan dev server
pnpm dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
pnpm dev          # Dev server
pnpm build        # Build produksi
pnpm start        # Production server
pnpm lint         # Lint
pnpm format       # Format kode
```
